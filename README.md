# Автоматический экспорт отчетов РИСО

Этот репозиторий содержит только установщики и описания обновлений. Исходный код приложения здесь не публикуется.

[Скачать последнюю версию](https://github.com/takedayoshimitsu/riso-report-exporter-updates/releases/latest)

Для пользователей не нужны аккаунт GitHub и токен. Условия использования и сведения о правообладателе находятся в лицензионном соглашении установщика.

Актуальная версия — 1.5.3 от 05.11.2026. Для перехода с 1.5.2 установите ее поверх старой версии один раз вручную; следующие обновления доступны в приложении → Обновления. Экспорт работает без Интернета. В этой поставке используется команда Проводника в «Показать дополнительные параметры».
